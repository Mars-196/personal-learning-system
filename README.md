# 个人成长系统

一个帮助用户管理个人成长目标的现代化 Web 应用，支持任务管理、阶段规划、反思记录等功能。

## ✨ 核心功能

### 📋 任务管理
- **待办任务**: 添加、编辑、删除、完成日常任务
- **任务分类**: 工作、学习、生活三大分类
- **重要程度**: 用罗马数字（Ⅰ-Ⅳ）标记任务优先级
- **时间管理**: 设置任务起止日期，查看任务进度
- **智能筛选**: 按日期、分类、状态、阶段、关键词筛选任务

### 🎯 阶段规划
- **树形结构**: 支持大阶段包含多个子阶段
- **时间规划**: 设置阶段起止日期，自动计算倒计时
- **进度跟踪**: 实时显示阶段内任务完成情况
- **灵活管理**: 添加、编辑、删除阶段，支持重新组织

### 💾 数据管理
- **本地存储**: 基于 IndexedDB 的浏览器本地存储
- **数据备份**: 支持导出全部数据为 JSON 文件
- **数据恢复**: 支持从备份文件导入，可选择合并或覆盖模式
- **数据安全**: 浏览器域名隔离，数据安全可靠

### 🔔 通知提醒
- **任务提醒**: 设置任务提醒时间，浏览器通知提醒
- **阶段提醒**: 阶段到期前自动提醒
- **完成通知**: 任务完成时发送庆祝通知
- **每日总结**: 每日定时发送任务完成情况总结

### 📝 反思记录（预留功能）
- **每日反思**: 记录每日心得体会
- **关联任务**: 反思可以关联相关任务
- **历史回顾**: 查看历史反思记录

## 🚀 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd 个人成长系统
```

2. **进入应用目录**
```bash
cd app
```

3. **安装依赖**
```bash
npm install
```

4. **启动开发服务器**
```bash
npm run dev
```

5. **打开浏览器**
访问 `http://localhost:5173` 查看应用

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `app/dist` 目录。

## 🌟 核心特性

### 服务层抽象
项目采用服务层抽象设计，数据访问通过统一的 Service 接口：
- 当前使用 IndexedDB 本地存储实现
- 预留了后端 API 接入能力
- 切换存储实现只需修改一个文件

### 类型安全
- 全面的 TypeScript 类型定义
- 前后端共用类型系统
- 编译时类型检查，减少运行时错误

### 响应式设计
- 移动优先的设计理念
- 流畅的过渡动画
- 良好的用户体验

### 数据安全
- 浏览器域名隔离存储
- 所有输入内容自动转义
- 支持数据备份和恢复

## 🚀 部署

项目支持多种部署方式，推荐使用 Vercel：

### Vercel 部署
1. 将项目推送到 GitHub
2. 在 Vercel 中导入项目
3. 配置构建命令：`cd app && npm run build`
4. 配置输出目录：`app/dist`
5. 点击部署

详细部署说明请参考 [部署运维文档](docs/DEPLOYMENT.md)。
